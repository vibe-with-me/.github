## Vibe With Me

[Vibe With Me](https://vibewithme.co) is an app for the people you meet at
shows. Tap a tag at a concert or a festival, and you stay connected with the
stranger who loved the same set you did.

### What we open-source

The core of Vibe With Me is open source, so anyone can build the same
handshake for their own people:

- **[withme-starter](https://github.com/vibe-with-me/withme-starter)**: a
  working app for meeting people in person around something you love. Tap a
  tag, see a card, connect. Web, mobile, API and database, with the privacy
  rules already written and tested. MIT.
- **[golf-with-me](https://github.com/vibe-with-me/golf-with-me)**: an example
  implementation. A complete fork of the starter for golfers, built to show
  how a fork is structured, from the renamed gathering to the new profile
  fields.
- **[@vibewithme/nfc](https://www.npmjs.com/package/@vibewithme/nfc)**: the
  tag-to-URL redirect SDK, usable on its own.

### What stays closed

The Vibe With Me app itself. A brand is a promise about who runs a product and
how it treats the people who use it, and we can only make that promise for the
one we run. The handshake, the privacy model and the security fixes live in
the starter, so every fork gets them too.

Built something on the starter?
[Tell us about it](https://github.com/vibe-with-me/withme-starter/issues/new).
